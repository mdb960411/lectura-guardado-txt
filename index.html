Conecta una pistola y escanea un código para comenzar.

Uso rápido

  1. Presiona Agregar pistola.
  2. Asigna un nombre y selecciona la velocidad, normalmente 9600.
  3. Presiona Seleccionar puerto COM y elige el lector.
  4. Configura Google Drive una sola vez con la URL de Apps Script y la clave privada.
  5. En Respaldo TXT en carpeta local, selecciona y autoriza la carpeta.
  6. Escanea. Cada lectura crea un TXT independiente en Drive y otro en la carpeta local.

La página debe abrirse desde GitHub Pages mediante HTTPS en Microsoft Edge o Google Chrome. El navegador solicitará autorización para cada puerto COM y para la carpeta local.
